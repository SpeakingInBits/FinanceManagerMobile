## Installing

Download the file for your device from **Assets** below.

### Android

`FinanceTracker.apk`, for Android 8.0 or later.

1. Open this page on your phone and tap `FinanceTracker.apk` to download it.
2. Open the downloaded file. The first time, Android asks whether your browser (or Files app) may install apps. Turn on **Allow from this source**, go back, and tap **Install**.

`FinanceTracker.aab` is the app bundle for uploading to Google Play. You don't need it to install the app.

If the files are named `-unsigned`, this release wasn't signed and Android won't install it as is. Sign the APK with your own key first (with `apksigner` from the Android SDK build tools), then install it.

### iOS

`FinanceTracker-unsigned.ipa` isn't signed, so an iPhone or iPad won't install it as is. Sign it with your Apple ID or developer certificate first, for example with a sideloading tool such as AltStore or Sideloadly, which install it for you.
